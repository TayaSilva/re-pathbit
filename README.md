# Pathbit Site

Site institucional estático da Pathbit feito com HTML, CSS e JavaScript puro, usando Vite apenas como servidor de desenvolvimento e empacotador.

## Scripts

```sh
npm run dev
npm run build
npm run preview
npm run lint
```

## Estrutura principal

- `index.html`: conteúdo indexável e estrutura da página.
- `src/App.css`: estilos das seções principais.
- `src/components/Hero/Hero.css`: estilos do hero.
- `src/index.css`: reset/base global.
- `src/main.js`: animações e interações em JavaScript puro.
