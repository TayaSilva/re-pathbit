# Pathbit Site

Site institucional estático da Pathbit feito com HTML, CSS e JavaScript puro, usando Vite apenas como servidor de desenvolvimento e empacotador.

## Scripts

```sh
npm run dev
npm run build
npm run preview
npm run lint
```

## Estrutura principal

- `index.html`: página principal do site.
- `legal.html`: página de documentos legais.
- `src/site.css`: estilos principais das seções.
- `src/hero.css`: estilos da área inicial.
- `src/base.css`: reset e base global.
- `src/main.js`: animações e interações em JavaScript puro.
